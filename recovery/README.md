# Recovery note

The blob preserved in this directory is the corrupted version of `lib/chapter-expansions.ts` from commit `1a1484efb301050eb574cf13a420e9fcf855cf90`.

GitHub stored the file as non-source binary-like data. It could not be decoded as the TypeScript text that the commit was intended to contain.

The production path was restored from the last known-good readable blob in commit `94b695295fd5616a45cdbff63868cd4ac4b28cec`.

The corrupted blob is retained only for forensic recovery. It is not imported by the application.
